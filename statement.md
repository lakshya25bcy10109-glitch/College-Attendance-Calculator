Project Statement: College Attendance Tracker

1. Problem Statement

The typical college requirement of maintaining a minimum attendance percentage (often 75%) creates significant anxiety and confusion for students. Students constantly struggle to perform manual calculations to determine their current status or, more critically, to figure out how many classes they can skip or how many they must attend to remain compliant. The lack of an instant, accurate, and actionable tool often leads to unnecessary stress, missed opportunities to use earned buffers, or falling below the minimum threshold without realizing it until it's too late.

The core problem is the absence of a simple, reliable, and instant calculator that translates raw attendance data into clear, decision-making advice.

2. Scope of the Project

This project provides a console-based attendance management system capable of tracking attendance for multiple subjects against a fixed minimum target (75%).

The scope is strictly limited to the following functionalities:

Tracking subject-wise and overall attendance counts.

Calculating percentages and status reports.

Providing actionable advice on required or skippable classes.

The system operates locally within the Python console and does not involve database storage, external APIs, or graphical user interfaces (GUIs).

3. Target Users

The primary and exclusive target users for this application are College and University Students who:

Are required to maintain a strict minimum attendance percentage.

Need quick, actionable data rather than complex reports.

Prefer a simple, command-line tool for focused, reliable calculations.

4. High-Level Features

The application delivers its value through the following high-level capabilities:

Attendance CRUD: The ability to Create (Add) and Update (Modify) subject attendance records.

Intelligent Reporting: Generation of an immediate, percentage-based status report ("Good," "At Risk," etc.) for any individual subject.

Predictive Calculation Engine: The core mathematical logic that advises the user on the exact number of classes needed to attend or the exact number of classes that can be skipped to maintain the 75% threshold.

Overall Summary: A consolidated report showing the aggregated attendance across all tracked subjects.
